# Domain Knowledge

Business logic and domain-specific rules that the pipeline needs to understand. This is NOT code — it's knowledge about what the code should do.

Examples for different project types:

**Travel app:** countries/, passport.md, customs-forms.md
**E-commerce:** products/, checkout.md, payment-providers.md
**SaaS:** tenancy.md, billing.md, permissions.md

Create domain files when the pipeline implements features that require business context beyond what the code itself shows.
