# Concepts

Cross-cutting concerns that apply across the project. These are universal principles applied to your specific context.

Examples:
- `drift-detection.md` — keeping derived artifacts in sync with source
- `error-handling.md` — how failures should be communicated
- `dependency-direction.md` — which modules can import which
- `separation-of-concerns.md` — what belongs where

Create a concept file when the pipeline discovers a principle that applies to multiple parts of the codebase.
